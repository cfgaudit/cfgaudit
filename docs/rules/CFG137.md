# CFG137: instruction text hidden behind a long run of blank characters

**Severity:** `warn`
**OWASP:** [LLM01:2026 – Prompt Injection](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10/blob/main/2026/final/LLM01_PromptInjection.md)
**Agents:** amp, antigravity, claude-code, cline, codex, continue, copilot, crush, cursor, devin, devin-desktop, gemini-cli, goose, grok, junie, kilo-code, kimi-cli, kimi-code, opencode, openhands, pi, qwen-code, roo-code, vscode, zed

## What cfgaudit checks

An instruction file (or prompt-hook text) where visible text is followed by 150 or more blank characters (spaces, tabs or Unicode space separators such as U+00A0 and U+3000) and then more visible text. The long gap pushes the trailing text out of view in editors and review while the agent still reads it as instructions.

Markdown table rows and fenced code blocks are skipped, as are runs followed only by a table cell separator (`|`) or a comment terminator (`-->`, `*/`).

## Why it matters

A long run of spaces hides a directive from a reviewer scrolling the file while the model still processes it, the same hiding vector as CFG024 (invisible Unicode) and CFG080 (HTML comments), using only ordinary whitespace.

## Remediation

Remove the hidden text or move it into a normal paragraph. If the spacing is intentional, shorten the run below 150 characters.
