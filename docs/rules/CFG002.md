# CFG002 — file-write grant reaches unrestricted or foreign-agent configuration

**Severity:** `warn`  
**OWASP:** [LLM03:2026 – Excessive Agency](https://github.com/GenAI-Security-Project/GenAI-LLM-Top10/blob/main/2026/final/LLM03_ExcessiveAgency.md)  
**Agents:** claude-code

## What cfgaudit checks

CFG002 reports two forms of Claude Code `permissions.allow` grant:

- A bare or wildcard-only `Edit` / `Write` grant that can overwrite any workspace file.
- A concrete or globbed grant that reaches configuration consumed by another agent, including Cursor, Codex, Gemini, qwen, Roo, Copilot, VS Code, or the shared repository MCP file.

The finding names the reachable files. This matters even when the broad grant was added for ordinary source edits: changing another agent's MCP, hook, task, or permission configuration can make that agent execute commands later under a different approval model.

An allow entry fully blocked by a deny in the same settings file is not reported. A partial deny remains reportable.

### Claude Code 2.1.317 sensitive-file gate

Measured on Claude Code 2.1.317 on Linux using an explicit `Edit(**)` setting and `--permission-prompts none`:

- `Edit` was denied for `.mcp.json`, `.vscode/settings.json`, and `.vscode/tasks.json`; the files did not change.
- The same `Edit` grant changed `.cursor/mcp.json` and `.codex/config.toml` without a permission denial.

Accordingly, when the detected Claude version is 2.1.317 or newer, CFG002 does not claim those three measured files are reachable through `Edit`. A broad `Edit(**)` finding instead names the still-reachable foreign configurations. An unknown or older version keeps the conservative finding.

This exception is deliberately tool-specific. It does not suppress `Write`, `MultiEdit`, `NotebookEdit`, Bash, or MCP tools; equivalent protection was not measured for them.

## Trigger example

```json path=.claude/settings.json version=2.1.317
{
  "permissions": {
    "allow": ["Edit(.cursor/mcp.json)", "Write(.codex/config.toml)"]
  }
}
```

## Safe alternative

Do not grant edits to another agent's configuration. Scope ordinary edits to the source directories that need them and add explicit denies for foreign configuration where a broad grant is unavoidable:

```json
{
  "permissions": {
    "allow": ["Edit(src/**)"],
    "deny": ["Edit(.cursor/**)", "Edit(.codex/**)"]
  }
}
```

## Relationship to the SchemaStore schema

Schema-aware editors reject wildcard-only rules such as `Edit(*)`, but they do not establish whether a syntactically valid concrete path crosses an agent boundary. CFG002 performs that semantic check during every cfgaudit scan.
